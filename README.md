<h1 align="center">Процессор RISC-V</h1>
<p>Проект создан в <b>Quartus 25.1 Pro</b> под плату <b>Terasic DE25 Nano</b> семейства <b>Agilex 5</b>.</p>
<p>На плате задействованы 8 светодиодов и 2 кнопки. Программа производит программный опрос кнопок, по нажатию на любую из них выполняется сдвиг горящего светодиода на одну
позицию влево.</p>

<h3>Листинг программы на ассемблере </h3>

```assembler
    addi   x1,   zero,   256
    addi   x2,   zero,   3
    addi   x3,   zero,   1
    xori   x4,   x3,     255
    addi   x5,   zero,   64
    mul    x6,   x1,     x5
    sb           x4,     0(x6)
    lw     x7,           16(x6)
    beq    x7,   x2,     -4
    slli   x3,   x3,     1
    bne    x3,   x1,     8
    addi   x3,   zero,   1
    xori   x4,   x3,     255
    sb           x4,     0(x6)
    addi   x8,   zero,   1
    addi   x9,   zero,   1200
    addi   x10,  zero,   1200
    mul    x11,  x9,     x10
    addi   x8,   x8,     1
    bne    x8,   x11,   -4
    jal    x12,         -52
```
<p>Исходные файлы процессора хранятся в папке <i>source</i>. </p>
<p>Машинный код программы хранится в файле <i>program1.hex</i>. Данный файл инициализирует память intel_onchip_memory v1.4.10 в системе на кристалле, размер памяти <b>16384 байта</b>.
Также в системе на кристалле присутствуют два периферийных модуля - шина параллельного ввода-вывода для кнопок и диодов.</p>
<h3>Карта памяти </h3>

```assembler
    0x0000_0000 - 0x0000_3fff    - память на кристалле
    0x0000_4000 - 0x0000_400f    - светодиоды
    0x0000_4010 - 0x0000_401f    - кнопки
```
<p>В модуле процессора обязательно необходимо указать параметры  начального адреса периферийного региона (<b>PERIPHERAL_REGION_LO</b>) и конечного адреса периферийного региона (<b>PERIPHERAL_REGION_HI</b>).</p>
<p><i>Периферийный регион</i> - некэшируемый диапазон адресов.
В процессоре предусмотрены кэши прямого отображения для инструкций и данных, размер каждой кэш памяти по 4 Кб.</p>
